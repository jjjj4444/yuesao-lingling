# 陈立玲月嫂服务小程序

一个个人月嫂服务展示小程序，包含首页介绍、宝宝护理、产后妈妈护理、月子餐菜谱和联系咨询。

## 页面

- 首页：服务简介、核心能力、服务内容入口
- 宝宝：新生儿护理说明与护理小百科
- 孕妇：产后妈妈护理说明与护理小百科
- 月子餐：按 7 类食材展示菜谱，支持左侧分类切换
- 联系：复制微信号、微信添加好友提示、拨打电话

## 图片

月子餐图片统一放在：

```text
assets/meals/
```

每道菜当前使用 `/images/default.png` 占位。后续上传真实图片后，可在 `pages/confinement/index.js` 中把对应菜品的 `image` 改成：

```js
image: '/assets/meals/菜名.png'
```
